# V20 / production Recovery09

Built on V19 and production Recovery08, preserving their jobs, balance, arenas, Legendary upgrades, NG+ experience and existing save format. Previous maps and the editor master are preserved. Creature Review 03s carries the same creature corrections.

## Cutscenes and controls

The shared cinematic entry now pauses the existing stat/hero refresh, inventory UI, gear UI, deferred cooldown work and profile capture/poll timers before unit pausing or selection changes. Gear events are disabled during that interval. Backpack, inspection, Talents, X, Move to hero and F/G controls are closed/hidden before the scene starts. Existing timers and events resume after exit; interrupted bag rebinds are deferred. Pending callbacks and load/save commands also check the cinematic gate before reading inventory. No synthetic cancel key is issued.

The profile clock and network transport remain running; they do not perform inventory scans. Capture/load timeout accounting excludes the paused scene duration. This is a handoff for the relevant systems, not a pause of every gameplay timer in the map.

Ordinary move, attack and spell orders no longer run the worn-equipment refresh that removes/re-adds abilities. They retain native item-transfer routing. Real equipment changes retain the existing refresh. This removes a broad source of control rebinding; whether it resolves cross-player bag closing requires a multiplayer test. The short native-panel adoption rejection window was removed to allow delayed panel binding to recover Talents, X and Move to hero. No second panel was added.

## Autosave

Automatic saves use the existing staged capture instead of pumping up to 400 capture steps synchronously. One capture step runs per 100ms while a save is active, with only one player capture started at a time. A large profile can take longer to finish, but its collection is spread across frames. Shared capture-validation failure requeues a retry after ten seconds. File-write success on one client does not control a shared retry decision.

Default-on scheduling remains minute 20, then every ten minutes; `-autosave off` is respected. Capture pauses during cutscenes and resumes afterward. Save encoding, file writing, manual capture and character load format are unchanged. Final encoding/file writing can still cause a hitch; zero freezing has not been demonstrated.

## Creature casting

Dark Dragon Marsh breath/fireball AI selects enemy heroes and uses an invisible native-spell proxy so the creature's attack orders cannot cancel its cast. The actual dragon pays mana and receives cooldown only when the native order is accepted. Existing damage, elements and effects remain.

Shadowdancer uses a temporary native illusion wand targeted at the enemy hero, with an explicit enemy-hero target ability. A resulting copy is checked against that hero's unit type and assigned to the Satyr. The temporary proxy/item are cleaned up; the actual hero's items are untouched. Existing Ancient Forest proximity restrictions remain.

## Validation and limits

Eleven focused tests pass. All four maps pass playable-script, editor-script, startup, source/global pairing and native saved-game text checks. All three full maps pass save-compatibility fixtures. Source verification confirms unchanged save codecs, arenas, XP/mastery logic, unit objects and unrelated modules. The only development object additions/changes implement the targeted illusion wand.

The supplied crash report is an access violation in V19 with six players, rather than a report identifying the first divergent script operation. It does not establish the exact cause. Live native casting, multiplayer bag ownership, cutscene crash/desync prevention and large-profile autosave smoothness remain unconfirmed.

Installed maps are recorded with hashes in `release/development/V20/installed.json`. Test V20 for full development, Recovery09 for production, and Creature Review 03s for isolated creatures.
