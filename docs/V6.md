## Solid rooted ancients

Structure classification alone does not produce a tile footprint. Each rooted ancient now creates four overlapping native YTpc ground pathing blockers at (+/-32,+/-32), forming a 192x192 footprint matching its96-unit collision radius. Installed Warcraft DestructableData confirms YTpc is the large ground-only blocker using4x4Default.tga, nonrendered and nonselectable. Map does not override it. Blockers are invulnerable and tracked in reserved F99Data unit keys600..603. They are removed idempotently on uprooting (even repeated cleanup), death and the shared cleanup used before consumption/removal. Existing active-unit heartbeat catches externally removed units. No new timer or owner-local gameplay path. Spawned rooted archers/wisps originate160 units to the side, outside the footprint. Mobile units retain V5's movement fixes.

The creature review exhibit creator had also disabled pathing for EVERY displayed creature, making movers ignore all obstacles. Review03j changes only that creator's SetUnitPathing to true so collision testing follows normal gameplay. Existing layout, selection, Normal stats, info/spells commands, split, combat controls and ownership are retained.
