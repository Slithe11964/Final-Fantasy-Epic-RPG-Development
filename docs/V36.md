# V36 and h Save01

Players report an autosave blocking further saves until -unstuck. One NG+10
character has extensive progress and another is earlier. Autosaves subsequently
stop for the lobby. -unstuck runs a short cinematic and resumes profile timers.
Whether a cinematic preceded the original stall remains unknown.

The shared scheduler previously returned on any busy player. An interrupted
validation could leave FSC_Busy set because FSC_Abort refuses a busy decoder.
FRC_Timeout now releases that flag for the capture-owned writer before aborting.
The existing scheduler completes captures whose phase ended but whose FFL save
phase remains active. A soft autosave still capturing at 60 active seconds is
aborted and its lock released, with a 30-second retry delay. Cinematic time is
excluded. Capture failures and validation/export failures queue a retry. A
player in retry delay no longer prevents another pending player from starting.
At most one successful capture starts per existing shared heartbeat.

Profile resume explicitly rearms the existing poll and capture timers. It
preserves watchdog time remaining. The profile poll restart helper follows the
callback declaration to satisfy JASS ordering. Existing callbacks, timer counts,
normal rates, capture validation, save format and file writer are retained.

Seven executable regression tests cover 60-second recovery, other players'
queue progress, finished captures, cinematic/load exclusion, busy decoder
cleanup, item drop/move/property rejection, timer restoration and capture/export
retry. Both builds pass map/editor/startup/source/globals/native-text checks and
fixed G/H save compatibility checks. Archive and unrelated runtime equality are
enforced. Actual NG+10 native throughput and multiplayer acceptance are pending.

Production Save01 derives from the published canonical h. Full development V36
derives from V35 and retains its restored Kalm/Gilgamesh dialogue. Installed as
distinct TEST maps. Current development V36, next V37.
