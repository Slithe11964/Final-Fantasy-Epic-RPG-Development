# V19: spell AI, Mastery icon, native previews and NG+ experience

2026-11-08. Base: V18 / production Recovery07. Outputs: V19, CreatureReview03q, Recovery08 modern and 1.29.2. User explicitly confirmed keeping the save format and selecting Legendary upgrades again after loading.

## Creature AI and Mastery

- Dark Dragon Marsh offensive spells now search specifically for a living, visible, non-illusion enemy hero within their native 800 range. The shared search previously used 600 and could choose a pet. Black Dragon prioritizes Omni Breath/Fireball before Devour and Elemental Shell; a rejected cast order can fall back rather than blocking all other choices. Existing mana/cooldown checks remain. Breath order `breathoffire` is confirmed in the installed game's ACbf definition. Damage, visuals and ranges are unchanged.
- Shadowdancer independently selects an enemy hero within Shadow Double's 600 range instead of skipping the spell when the shared target is a pet. Existing clone mechanics are unchanged.
- All F99 automatic ability choices, including summons, Sylph support and Infernal taunt, require an eligible enemy within 2000. Rooted Tree of Life / Ancient of War production also checks that radius at each five-second spawn. Suppressed production schedules the next check from the current time, preventing catch-up bursts. Existing effects, cleanup, expiry and unit movement are not frozen by that distance gate.
- Mastery A02F was explicitly hidden at ranks 5-9 (the alternate Legendary choices). Set its native **Ihid Data D / pointer 4** to false at those ranks. Rank 1 remains hidden; existing rank 2-4 behavior, icon, slot and tooltips remain. No new frame/overlay or gameplay multiplier is used for this icon fix.

## Native inventory changes

The six-slot previews were deliberately removed by the dated-f rollback. Restore only the known QuickUI75/slot76/preview77 visual function delta from the corresponding UI74 base: fresh slot/raw lookup on each native click, correct adjacent columns, selection tracking for hero or Gaya, and wave geometry originating from the loaded hero. Keep current cinematic gates on affected entry points. No Idle76 inventory cache, Inventory94 catalogue, load isolation, item conversion or item-moving overlay is restored. Native item placement/tooltips remain native. The classic build has no matching frame-based UI and keeps its existing native controls.

The prior ownership route did not resolve the owner's cross-player close report. `Forsaken_HideInventory` now addresses only the three already-bound panes, checks that the binding belongs to the local player's hero, and never iterates/hides every cached context. The visibility poll no longer calls HideInventory or clears local open intent after transient visibility loss. A different native context can be adopted only during an explicit local B/button request window. It does not force open an inactive pane or create another panel. This removes a broad hiding path, but is a candidate fix: the exact native multiplayer failure was not reproduced or proven here.

These changes are private presentation only. No frame/selection/cursor result determines the new XP gameplay logic, and no new local unit/item mutation, shared snapshot, sync protocol, frame search or gameplay polling timer is added.

## NG+ experience

`1 + 0.10 x max(0, saved NG+ cycle count)` multiplies earned experience. NG+9 = x1.9 / +90%, not exponential compounding. The current counter is already stored in the existing save format.

- Monster XP is boosted once before it is granted or banked; both hero and Gaya retain existing secondary XP rules. Firefly bank redemption does not boost it again. The existing bank cap remains.
- Central quest rewards and Arena BP-to-XP purchases receive the same per-player factor. Death XP penalties are unchanged.
- A hidden command-card aura supplies a visible self-only status to hero and Gaya, with distinct level descriptions from +10% through +100%. NG+9 uses bE09 with +90% text. The aura itself gives zero movement/attack-speed changes; XP math reads the NG+ count and does not rely on a dispellable status.
- Uses the existing shared stats refresh to attach/update the status after loads and job changes, with no new timer. Re-arm that existing two-second one-shot timer before the cinematic gate: the earlier early-return could otherwise stop all later stats refresh after a cutscene. Its actual work still waits until shared cinematic flags clear.
- Native Tome of Retraining icon asset verified in installed CASC (DDS equivalent). No dynamic global tooltip changes between players.
