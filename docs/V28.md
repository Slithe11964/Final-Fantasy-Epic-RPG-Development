## Display changes

Intermediate Recovery17 from Recovery16 and V28 from V27 change two functions:

- `QuickGear_Layout` exactly restores the original command-button-7 top-right
  anchor with .012 horizontal gap. Existing .040-square buttons and .046 row
  spacing remain.
- `QuickGear_Init` creates the regular dock under the existing native portrait
  frame's parent, resolved once in shared initialization. This is a proposed
  widescreen-capable display ancestor different from ConsoleUIBackdrop, whose
  children render beneath SimpleFrame console art. It does not move, reparent,
  show or hide the actual native portrait/console.

an alternative for frames outside the central band:
https://www.hiveworkshop.com/pastebin/e23909d8468ff4942ccea268fbbcafd1.20598

in this Warcraft build remains unverified.
