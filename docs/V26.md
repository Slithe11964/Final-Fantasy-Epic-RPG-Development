## Focused candidate

Recovery15 starts from Recovery14; V26 starts from V25. Only `QuickGear_Init`
changes. Exactly one argument expression is different: the regular FRAME root
is owned by the native regular `ConsoleUIBackdrop` instead of `GAME_UI`.
The native frame lookup runs in shared startup, not local input/polling.

The regular dock is positioned to the right of native command button 7, which
can extend beyond the central 0–0.8 UI band. Regular controls under GAME_UI
can be clipped there. The original frame-system author's guidance explicitly
identifies ConsoleUIBackdrop as an owner allowing regular frames outside that
band. This is a supported display correction and a plausible explanation for
the missing dock; the actual native result is still unverified.
