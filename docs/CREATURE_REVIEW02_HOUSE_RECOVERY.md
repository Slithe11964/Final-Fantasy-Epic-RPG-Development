# House recovery and Creature Review 02

2026-10-31 owner update.

House recovery is 5% of each eligible nearby unit's maximum health and maximum mana per second. House h006 and transformed h00N use dedicated hH79/hM79 native regeneration aura clones with percentage flags enabled. Their original 350 range and targets are preserved. The Fountain of Restoration still uses unchanged A001/A00F; no global aura rebalance occurs. Ability descriptions state the new rates. No runtime code, timers, inventory UI, previews, saves, items or other units change in these RPG candidates. Outputs are QuickUI78, retained-jobs 0.9.7.5f Hotfix09, and matching 1.29.2 house patch from the current classic release. Original master and release files remain unchanged.

Creature Review 02 is a separate modern-client map based on normal-f monster data. It contains 689 exhibits covering the same 419 distinct original types, with intentional area/encounter duplicates. Normal is explicitly difficulty3, scale1, 100% one-player handicap. Player0 inherits authored enemy research (including proficiency research5), identified hero spawn levels, six-slot starting gear and authored spell ranks. Default invulnerability and Avul are removed. Selecting a unit only remembers it; no automatic text is printed.

- -info: source areas/encounter category; current/max HP and MP; live accuracy and evasion through the actual game functions; armor/NPC native magic defense; base attack plus dice, attack interval, movement speed, STR/AGI/INT for heroes, base regeneration and all seven elemental resistance tiers with multipliers. Base regeneration excludes added auras/scripts; attack is base plus dice rather than a guaranteed final damage total. Missing practice-target catalogue text is guarded instead of printing null.
- -abilities [page]: on-card native ability values and conditional scripted calculation details, with longer expressions paged. Spell tooltips also have calculation/effect sections; long traces direct readers to the command.
- -spells [page]: unit-specific extra scripted effects, damage/healing, phases, summons and ability/order changes. These are source-derived conditional/intermediate expressions, not unconditional totals.
- -area10: Arena of Darkness; -area11: story/world encounters; -area12: Battle Arena; -area13: practice. Areas1-9 retain normal and late/Boundary lineups. Shared creatures intentionally appear in multiple appropriate sections. Known encounter names such as GilgameshII/Ozma/Penance/Shinryu are shown with their underlying unit names.

Spell-Calculations.md/JSON contain full rank entries and source-derived scripted equations. Native metadata/field labels and stock ability descriptions are read from installed Warcraft assets, not guessed. The invalid original m02A pool reference remains audited and uninstantiated. The isolated review does not start the complete RPG damage pipeline, loot, quests, save/load or automatic boss AI; normal stat/setup references and manual native/pure-spell handlers are provided, not full encounter simulation. Some scripted values depend on encounter state and are kept symbolic. No new monster role redesign is implemented.
