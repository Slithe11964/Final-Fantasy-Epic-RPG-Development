# Warcraft III 1.29.2 compiler libraries

Copied from the existing MapToolkit 1.29.2 conversion toolchain. These version-specific
common.j and blizzard.j files are used only to compile-check the converted playable
script; tools/bin contains the Reforged development check libraries and pjass.exe.
The baseline manifest records their hashes. These files do not replace the game's files.
