Save Code Name Swap

A save code only loads for the account that saved it. When a player renames their Battle.net account, paste their code here to make the same code for the new name. Jobs, items, titles and the armory stay exactly as they were.

How it works
  • The first field of every code is a 20-bit hash of the account name: abs(StringHash(name)) mod 2^20. The game compares it with the loading player's name.
  • This page rewrites only that field and the 3-character checksum, which is characters 2 to 8 of the code.
  • The armory part (in brackets) starts with its own checksum and a copy of the main checksum, which is how the game checks that the two parts belong together. Those 6 characters are rewritten too; the armory itself is unchanged.
  • Long codes don't fit in one chat line. Type -load with the code first, then -loada (…) with the bracket part.
  • Same method as tools/savecode.py rename in the FFERPG repository, and checked against real codes.
  • Works for current codes (they start with G or H). Everything runs in your browser; nothing is sent anywhere.
